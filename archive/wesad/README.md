# WESAD Archive

This folder holds this project's historical, user-run WESAD artefacts. The current active manuscript and experiments are EmoWork-focused, primarily under [paper_v2](../../paper_v2), [runs/emowork](../../runs/emowork), and [results/emotion/emowork](../../results/emotion/emowork).

WESAD remains relevant as comparison literature in `paper_v2` related work and references. Those citation/comparison mentions are intentionally not archived or removed.

## Contents

- `runs/` -- previous `runs/wesad` logs, comparison scripts, and sequence-stat outputs.
- `results/` -- previous WESAD experiment outputs from `results/emotion/wesad*` and `results/emotion/smoke_v5`.
- `logs/` -- WESAD-specific logs that were previously mixed into active EmoWork run logs.
- `paper/` -- the earlier WESAD honest-evaluation write-up and figures.

The active source package still contains WESAD loader/training support where it already existed. That code was left in place intentionally so shared training utilities and any historical entry points are not broken by this archival cleanup.
