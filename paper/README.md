## Reproducing the headline numbers

LOSO (Section 6):

```bash
.venv\Scripts\python.exe -m empathic.train --dataset wesad --target quadrant --fusion
.venv\Scripts\python.exe -m empathic.train --dataset wesad --target valence  --fusion
.venv\Scripts\python.exe -m empathic.train --dataset wesad --target arousal  --fusion
```

Protocol audit (Section 8):

```bash
.venv\Scripts\python.exe runs\relaxed_eval.py
```

Headline metrics are written to `results/emotion/wesad_v5/wesad/<target>/
summary.csv` (LOSO) and `runs/wesad/relaxed_eval4.log` (four-protocol).
